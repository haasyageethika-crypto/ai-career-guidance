# AI Career Guidance Platform

A responsive career-guidance website designed to help students and parents explore careers, courses, entrance exams, roadmaps, scholarships, and learning resources.

## Features
- Student and parent guidance sections
- Career discovery quiz and career recommendations
- Career/course information and comparison tools
- Roadmap planning
- Scholarship and learning-resource links
- Education cost planning estimate
- Responsive layout for desktop and mobile

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

No build step is required for this static website. Google Fonts are loaded from the internet; the page may use fallback fonts if offline.

## Important note
Career costs, exams, eligibility, scholarships, and course details can change. Verify current information through the official websites linked on the page before making education decisions.
